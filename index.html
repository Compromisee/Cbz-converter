Features

Everything you need to organize your library

From simple conversion to advanced metadata aggregation, all in one tool.

search

Multi-API Lookup

Queries MangaDex, MyAnimeList, AniList, and Kitsu simultaneously. Merges results for the most complete metadata possible.

bolt

Multithreaded

Process multiple volumes in parallel with configurable worker pools. Live progress tracking per worker.

auto_fix_high

Smart Parsing

Recognizes 25+ filename patterns. Per-volume chapter ranges, dates, and covers automatically detected.

picture_as_pdf

Lossless Output

Uses img2pdf for lossless PDF generation. Auto-detects page size from source images. EPUB3 fixed-layout for e-readers.

visibility

See exactly what will be renamed and where it will go before any conversion happens. No surprises.

Quick Start

Install and run in 30 seconds

Pick your preferred interface — they all share the same powerful engine.

# Clone and install git clone https://github.com/yourusername/cbz-converter.git cd cbz-converter pip install -r requirements.txt
# Launch the web dashboard python converter.py --web # Or specify a custom port python converter.py --web --web-port 8080 # Opens automatically at http://localhost:5000
# Convert with auto-detected metadata python converter.py *.cbz --auto --select 1 # Custom naming format python converter.py *.cbz --auto --select 1 \ --name-format "{manga_name} v{volume} ({date})" # EPUB output, 8 workers, max quality python converter.py *.cbz -f epub -w 8 -q 95 # Preview without converting python converter.py *.cbz --auto --dry-run # Don't rename, just convert python converter.py *.cbz --keep-name
# Launch the desktop GUI python converter.py --gui # Or just run with no args (auto-launches GUI) python converter.py
How It Works

From CBZ chaos to organized library

Four steps from messy filenames to perfectly named PDFs and EPUBs.

1

Parse Filenames

Detects manga name, volume, chapter, group, and year from any of 25+ naming conventions.

2

Query APIs

Searches MangaDex, MAL, AniList, and Kitsu in parallel. Merges results for completeness.

3

Resolve Metadata

Per-volume chapter ranges, titles, dates, and covers fetched from the most authoritative source.

4

Convert in Parallel

Multithreaded PDF/EPUB generation with live progress. Custom naming applied automatically.
